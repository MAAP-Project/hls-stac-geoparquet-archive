# Project introduction slides

The [HLS STAC GeoParquet Archive introduction deck](../presentations/esdis-tech-spotlight-2026-11-17/) is an editable starter for introducing the project to NASA scientists and engineers. It explains what the metadata archive contains, how CMR records are organized as monthly GeoParquet with static Iceberg metadata, and where the current snapshot is incomplete.

The deck is built separately from MkDocs and placed at `presentations/esdis-tech-spotlight-2026-11-17/` in the generated site. See the repository README for local preview commands.
